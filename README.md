# Asset Test Course

This is a course for testing features of asset file storage in Open edX courses. Course ID should be: `course-v1:OpenCraftX+ATC+2026`.

This course contains nine assets, and tests different ways of referencing them and different edge cases for file names with special characters or conflicting with each other.

To generate an export from the git repo, run `git archive --format=tar.gz -o ../assets-course.tar.gz HEAD`
