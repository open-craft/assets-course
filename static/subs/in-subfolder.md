# In Subfolder

This asset is stored in `subs/in-subfolder.md` in the course export. However, when viewed in Studio, the subfolder is not visible. The subfolder is preserved across import-export roundtrips, however. This feature (having a different path on export than seen in Studio) works only for the *subfolder* part of the path - it is not possible to have a filename like `export.md` in the course export and `import.md` when imported to Studio that survives roundtrips.
